# claims_blind2

This set of 30 reports was written from the label definitions and WORLD.md only, with no access to the tool, its source, its tests or its benchmark files. Each report describes the world in WORLD.md in a different style (Slack, model cards, logs, tables, FAQ, long sentences) and has a matching caseNN.labels.json with one label per claim in document order. Totals (146 claims): mismatched 17, orphaned 29, stale 12, cherry-picked 13, traced 52, untrusted-source 23.
